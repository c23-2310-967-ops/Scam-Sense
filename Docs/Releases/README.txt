SCAM SENSE: THINK BEFORE YOU CLICK
Version {VERSION} - Windows 64-bit

A first-person 3D investigation game that teaches players to spot scam messages
before they click. BSIT Capstone Project.


HOW TO RUN
1. Extract the whole ZIP file to a folder (for example your Desktop).
   Do not run the game from inside the ZIP.
2. Open the folder ScamSense-v{VERSION} and double-click ScamSense.exe.
3. If Windows shows "Windows protected your PC", click "More info" and then
   "Run anyway". The game is not code-signed, so Windows does not recognise it.
4. On the main menu, choose PLAY. Room 1 is always open; each later room
   unlocks when you reach the previous room's passing score.

Keep every file and folder together. ScamSense.exe needs ScamSense_Data,
UnityPlayer.dll and MonoBleedingEdge next to it.


SYSTEM REQUIREMENTS
- Windows 10 or 11, 64-bit
- DirectX 11 graphics (integrated graphics is fine)
- 4 GB RAM (8 GB recommended), about 1 GB free disk space
- Keyboard and mouse
- Internet is optional: needed only for online accounts and cloud sync


CONTROLS
Move ........................ W A S D
Look around ................. Mouse
Jump ........................ Space
Interact (phone, computer,
  doors, chairs, case items)  E
Stand up from a chair ....... Space or E
Answers and buttons ......... Mouse click
Show / hide objectives ...... Tab
Start the level ............. Enter (or BEGIN INVESTIGATION)
Pause / leave the computer .. Esc (P also pauses)


SAVED PROGRESS
Progress and settings are saved automatically on this PC (Windows registry,
HKEY_CURRENT_USER\Software\DefaultCompany\Capstone). Deleting the game folder
does not delete progress; use RESET PROGRESS on the main menu for that.


WHICH VERSION IS THIS?
The version is shown in the top-right corner of the main menu.
BUILD_INFO.txt lists the exact source commit this build was made from.
RELEASE_NOTES.txt lists what is included, fixed and still known.


All senders, brands, names and links in the game are fictional.
No real link is ever opened.
